# 素材来源与版权说明

核对日期：2026-09-12。比对方法是**按文件内容 md5** 逐一核对，而不是只看文件名
（原版有的资源改了名照样是原版内容，本工程也有同名但重画过的图）。

## 结论

`src/**` 下共 113 张图片：

| 路径 | 数量 | 来源 | 随仓库分发 |
|---|---|---|---|
| `src/common/chess/**`（象棋子、国象子、军棋子、斗兽棋子、飞行棋子） | 90 | 原版《方寸棋阁》包内资源 | ✗ 不可 |
| `src/common/map/**`（棋盘底图） | 8 | 同上 | ✗ 不可 |
| `src/common/ui/**`（界面图标） | 11 | 同上 | ✗ 不可 |
| `src/common/logo.png`（应用主图；与原版内容一致，只是改了文件名） | 1 | 同上 | ✗ 不可 |
| `src/common/icon/b.png`、`src/common/icon/w.png`、`src/common/icon/ttt.png` | 3 | 本工程自制 | ✓ 可以 |

**110 / 113（97%）是原版素材，版权属于原版作者（YDNAC）。** 因此 `.gitignore` 里排除了
`src/common/chess/`、`src/common/map/`、`src/common/ui/`、`src/common/logo.png` 这四处
（这三个目录里只有 PNG，所以按目录排除是精确的）。

复现核对：

```bash
python - <<'PY'
import zipfile, os, hashlib
BS = chr(92)
z = zipfile.ZipFile(r'F:\xiazai\方寸棋阁（围棋，国际象棋，斗兽棋，飞行棋，五子棋，象棋，军棋）.bin')
orig = {}
for n in z.namelist():
    if n.lower().endswith(('.png', '.jpg')):
        try: orig[hashlib.md5(z.read(n)).hexdigest()] = n
        except Exception: pass
same = ours = 0
for root, dirs, files in os.walk('src'):
    for f in files:
        if not f.lower().endswith(('.png', '.jpg')): continue
        p = os.path.join(root, f)
        m = hashlib.md5(open(p, 'rb').read()).hexdigest()
        if m in orig: same += 1
        else:
            ours += 1
            print('自制:', p.replace(BS, '/'))
print('原版素材 %d 张 / 自制 %d 张' % (same, ours))
PY
```

## 自备素材（clone 之后怎么跑起来）

代码本身不依赖这些图，但画面会缺。把自备素材放回对应路径即可：

| 缺什么 | 放到哪 | 说明 |
|---|---|---|
| 棋子与棋盘图 | `src/common/chess/**`、`src/common/map/**` | 各类棋子 PNG，命名见 `src/common/core/*.js` 里的 `pieceImage()` |
| 界面图标 | `src/common/ui/**` | 见 `src/common/core/games.js` 的 `icon` 字段 |
| 应用图标 | `src/common/logo.png` | 可直接用仓库里的自制占位图：`cp docs/placeholder/logo.png src/common/logo.png` |

`docs/placeholder/` 下有两张自制占位主图（128 / 256，纯自绘，可自由使用）。
缺图**不影响编译**（`bash tools/build-bin.sh` 照样能出 `.bin`），只是对应位置空白。

## 关于发布

`bash tools/build-bin.sh` 产出的 `dist/*.bin` **内置**了上述素材，因此：

- 自用、装自己手环：没问题。
- 公开分发（网盘、论坛、Release 附件）：请先换成自制素材再打包，否则等于传播他人美术资源。

游戏规则文案（`src/common/core/games.js` 里的 `help`）参考原版玩法后**重写**过；
规则与玩法本身不受版权保护，复用的是写法，不是原文。
