# 模拟器（小米手环 10）

用官方 `@aiot-toolkit/emulator` 起的 Vela 虚拟机。**已经在本机跑通**：能创建 212×520 的
小米手环 10 虚拟机、启动 Vela 系统、装我们的 `.bin`、并在日志里看到系统 launcher 认出应用名
「棋类博弈」。下面是可以照抄的完整流程。

## 1. 一键脚本

```bash
node tools/emulator.cjs setup  [虚拟机名] [镜像类型] [皮肤名]   # 建虚拟机（默认 band10）
node tools/emulator.cjs startbg band10                        # 后台启动，日志写 .emulator.log
node tools/emulator.cjs start  band10                         # 前台启动
node tools/emulator.cjs list                                  # 列出已有虚拟机
node tools/emulator.cjs stop   band10                         # 停止

node tools/emulator-shot.cjs band10 out.png                   # 走 gRPC 截图（会先点一下唤醒屏幕）
npx aiot start                                                # 编译+安装+启动应用（会问一句，回车即可）
```

`tools/emulator-shot.cjs` 用的是官方 gRPC 通道，同一套接口还能发触摸/按键事件
（`agent.sendMouse({x,y,buttons})` / `sendKey`），所以能拿来做真机交互测试。

## 2. SDK 资源（约 1.6 GB，装在 `~/.vela/sdk`）

官方 CDN：`https://vela-ide.cnbj3-fusion.mi-fds.com/vela-ide/...`

| 部件 | 地址 | 解压到 |
|---|---|---|
| emulator | `emulator/v0.1.0/windows-x86_64.zip`（318 MB） | `sdk/emulator/windows-x86_64/` |
| qa | `qa/v0.0.1/qa.zip`（27 MB） | `sdk/qa/` |
| skins | `skins/v0.0.10/skins.zip`（0.9 MB） | `sdk/skins/` |
| modem_simulator | `modem_simulator/v0.0.3/modem_simulator.zip` | `sdk/modem_simulator/` |
| 系统镜像 A | `system-images/vela-miwear-watch-5.0/20250716/vela-miwear-watch-5.0.zip`（366 MB） | `sdk/system-images/vela-miwear-watch-5.0/` |
| 系统镜像 B | `system-images/vela-watch-5.0/20250716/vela-watch-5.0.zip`（210 MB） | `sdk/system-images/vela-watch-5.0/` |

> 注意平台名要拼成 `windows-x86_64`（不是 `windows-x64`，后者 404）。
> 也可以直接 `npx aiot initEmulatorEnv` 让工具链自己下（它会 `force:true` 全量重下）。
>
> 装完要在 `sdk/versions.json` 写一份版本号，否则工具链会认为 SDK 不完整而触发重下
> （`tools/emulator.cjs setup` 会自动写）。

## 3. 皮肤与镜像怎么选（关键）

`skins/` 里自带真机皮肤，其中 **`user/xiaomi_band_10` 就是小米手环 10**：

```
parts { device { display { width 212  height 520 } }
        portrait { background { image background.png } foreground { mask foreground.png } } }
props { shape pill-shaped  density 320  flavor band }
```

`createVvd` 传 `skin` 时会把 `skin.dynamic=yes`，屏幕尺寸与胶囊圆角由皮肤决定
（配置里 `hw.lcd.shape/density/flavor` 显示 `undefined` 是正常的，运行时从皮肤读）。

两种镜像的区别（实测）：

| 镜像 | 系统界面 | 适合 |
|---|---|---|
| `vela-miwear-watch-5.0`（默认） | **圆表**表盘界面（天气卡片那种），屏幕尺寸由皮肤给 | 看系统 UI，但与手环观感不符 |
| `vela-watch-5.0` | **不带表盘**，待机画面是黑的，但 quickapp 框架/launcher 正常（照样能安装并启动应用） | 调试应用本身 |

所以「系统是圆表的」那个问题来自镜像：要用 `vela-watch-5.0` 这份。

```bash
# 换成不带表盘的镜像 + 手环 10 皮肤
node tools/emulator.cjs setup band10v5 vela-watch-5.0 xiaomi_band_10
# 把镜像文件同步进虚拟机目录（createVvd 是从"默认镜像"目录拷的，换镜像后要手动同步一次）
cp -f ~/.vela/sdk/system-images/vela-watch-5.0/{nuttx,vela_data.bin,vela_system.bin,coredump.core,advancedFeatures.ini} \
      ~/.vela/vvd/band10v5.vvd/
node tools/emulator.cjs startbg band10v5
npx aiot start
```

## 4. 实测记录与坑

- 启动日志里的关键行：
  `Setting display: 0 configuration to: 212x520, dpi: 160x160` → 屏幕尺寸正确；
  `NuttX 12.3.0 ... arm miwear` → Vela 系统在跑；
  `[launcher] launcher_page_remove_icon: remove icon: 棋类博弈` → 系统认出了我们的应用名。
- **`aiot start` 会问一句**「there is only one emulator, need to Run? (Y/n)」，
  非交互环境要喂输入：`printf 'y\ny\ny\n' | npx aiot start`。
- **`adb` 不用自己装**：工具链自带 `node_modules/@miwt/adb/bin/win/adb.exe`。
  设备是 NuttX（`nsh`），没有 Android 的 `pm/cmd`；卸载/安装要走
  `adb -s emulator-5554 shell pm uninstall|install <pkg|rpk>`（由工具链内部调用）。
- **改了代码一定要升 `versionCode`**，否则安装会被跳过、看到的还是旧页面（这个坑踩过）。
  想彻底干净：`adb -s emulator-5554 shell pm uninstall com.byxz.qileiboyi` 再 `npx aiot start`。
- **gRPC 截图只在画面真的变化后才更新**；待机久了屏幕会休眠、截到的是最后一帧，
  所以 `emulator-shot.cjs` 会先点一下唤醒。
- **displayWidth 用 `"device-width"`**（与原版方寸棋阁一致）：`px` 就等于设备像素，
  `100%` 等于设备宽度。实测在 212 宽的屏上 `width:100%` 正好量到 212px ✓。
  如果写成固定数值（如 `212`），框架会按"设计稿宽度→屏幕宽度"再缩一次，画面会整体放大溢出。
- 本机 `WHPX 已安装可用`（`emulator-check.exe accel`），ARM 镜像走软件模拟，冷启动约 40~60 秒。

## 5. 没能在模拟器上完成的部分

`vela-watch-5.0` 这份镜像装应用、跑 JS 都正常，但**截图是黑的**（它没有表盘与合成器），
所以「肉眼验收界面」这一步在模拟器上做不了。要目视确认，建议：
用 AIoT-IDE 自带的设备预览，或把 `dist/棋类博弈_byxz.bin` 装到真手环上。

界面排版本身可以用仓库自带的 HTML 预览器先看：
`node tools/preview.mjs && bash tools/preview.sh` → `tools/preview/out/*.png`。
